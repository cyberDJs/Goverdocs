# Documentation Governor Foundation

## Goal

Deliver a reusable, provider-independent documentation governance kernel for CyberCore, VOODOO One and other projects.

## Scope

- policies and schemas,
- deterministic classifier and planner,
- validator,
- registry and relationship graph,
- receipts,
- CLI and CI,
- open-source governance tooling integration with pinned presentation and evidence producers.
